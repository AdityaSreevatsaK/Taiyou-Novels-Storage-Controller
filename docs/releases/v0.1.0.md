# Taiyou Novels Storage Controller v0.1.0

**First tagged release** of the Storage Controller (11 November 2026).

This version consolidates the working local/private Hugging Face storage
utilities and the November reliability and production-readiness fixes.

## Highlights

- **Novel upload integrity:** compare original ZIP, EPUB and source-managed
  catalogue fields before declaring a novel unchanged; selectively repair
  corrupt/missing artifacts without overwriting unchanged binaries.
- **Metadata safety:** preserve stable book identities, reading progress,
  personal tags/ratings/notes and source genres absent from older ZIPs.
- **Cover importer:** atomic batches, conservative matching, resume after
  interrupted batches and bounded handling of Hugging Face rate limits.
- **Safer operations:** limit ZIP expansion and entry counts; require
  revision-guarded confirmation and check changed local ZIPs before commits.
- **Destructive-action protection:** removed backup-free GitHub deletion.
  Full data reset stays local, interactive and verified-backup-first.
- **Maintenance:** pinned Python dependency graph and GitHub Actions commit
  SHAs, clearer documentation and executable smoke tests.

## Verification

**87 tests passed** in all four GitHub CI combinations:
Windows/Linux × Python 3.11/3.12. End-to-end tests use synthetic novels
and a simulated revision-aware **private** Hugging Face dataset.
**No live Hugging Face production data was modified.**
